# HeatBall Game

A 3D brick breaker game developed using Unity and C#.

## Features
- 3D brick breaker gameplay.
- Ball and paddle mechanics.
- Brick collision and destruction.
- Score and lives management.
- Multiple game levels.
- Visual effects and animations.

## Technologies
- Unity
- C#
- TextMesh Pro

## Project Structure
- `Assets/` – Game assets, scripts, scenes, prefabs, materials and UI.
- `Packages/` – Unity packages and dependencies.
- `ProjectSettings/` – Unity project configuration files.

## Türkçe Açıklama

HeatBall, Unity oyun motoru ve C# kullanılarak geliştirilmiş 3 boyutlu bir blok kırma oyunudur. Oyunda top ve platform mekanikleri, blok etkileşimleri, skor ve can yönetimi ile birden fazla seviye bulunmaktadır.
